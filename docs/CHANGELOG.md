## v3.0.0 · 文笔与审美升级

### 新增
- **文笔风格预设**：冷峻克制 / 古典雅致 / 电影感 / 烟火气 / 悬疑张力；注入规划、写作、校验、自由写作、多候选提示词。
- **文笔实验室**：`POST /api/prose/analyze` 规则分析句长、句长波动、对话占比、感官密度、副词密度、段落节奏、AI 味，输出文笔分、指标和可执行建议。
- **文笔精修**：按风格调用 `POST /api/ai-polish`，预览后替换；替换前自动保存版本，支持回滚。
- **命令面板**：`Ctrl+K` / 右上角 `⌘K`，覆盖新建项目、章节、保存、文笔实验室、AI 味检测、专注、搜索、主题、API、导出。
- **极光金墨主题**：深海军蓝 + 暖金，3.0 默认主题。
- **衬线正文层**：编辑器/预览使用中文衬线字体，行高 2.08，760px 限宽。
- **自动保存状态**：保存中 / 已保存 HH:MM:SS / 保存失败。

### 优化
- 3.0 默认端口 8082，2.0 保持 8081，可同时运行、对比。
- 生成区、右侧面板、弹窗、滚动条、过渡统一为 v3 视觉层；支持 `prefers-reduced-motion`。
- 多候选接口支持 `prose_style`，保持候选之间的文笔一致。
- 文笔实验室对短文本给出样本不足提示，避免指标误读。
- 发布文档、启动脚本、版本号更新到 3.0。

### 继承 2.0
- 恢复被隐藏的 AI 生成入口、9 种创作模式、多候选、专业模式、选中文字 AI 操作。
- 本地优先监听、CORS 收敛、静态资源缓存、外部背景下载移除、失效面板清理、无真实 Key 发布。
