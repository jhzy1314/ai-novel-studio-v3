## 3.0 改了什么

2.0 已经能生成、能管理、能协同，但还有几个明显的不足：

- **文笔不可控**：只能选「文艺 / 严谨」这种粗粒度模式，无法指定「冷峻 / 古典 / 电影感 / 烟火气 / 悬疑」。
- **不知道哪里写得不好**：没有句长、节奏、对话、感官、副词、AI 味的可解释反馈。
- **改文笔只能重写**：缺少「保留剧情、只精修文字层」的入口。
- **审美不统一**：默认深色偏工具化，正文是 UI 无衬线字体，生成区控件拥挤。
- **常用操作路径深**：新建项目、开文笔实验室、保存版本、切换主题都要找菜单。
- **和 2.0 抢端口**：两个版本都用 8081，无法同时打开对比。

3.0 对应做了这些：

### 1. 文笔风格预设（真正注入生成）
顶部新增「✒️ 文笔」下拉：冷峻克制 / 古典雅致 / 电影感 / 烟火气 / 悬疑张力。  
选择后会注入规划师、主笔、校验官、自由写作、多候选的提示词，只改文字层，不改剧情与人设。

### 2. 文笔实验室
右侧新增「✒️ 文笔实验室」：

- **分析本章**：句长、句长波动、对话占比、感官密度、副词密度、段落节奏、AI 味规则，给出 0–100 文笔分和可执行建议。
- **按风格精修**：调用主笔模型做「保剧情、改文字」的精修，先预览再决定是否替换。
- **替换前自动备份**：当前正文会先存成一个版本，精修失败或不满意可以回滚。
- 分析本身是纯规则，不消耗 token。

### 3. 审美层：极光金墨
- 新主题 **极光金墨**（深海军蓝 + 暖金），作为 3.0 默认主题。
- 正文改为**中文衬线字体**，行高 2.08，编辑器限宽 760px，读起来更像书。
- 生成区、右侧面板、弹窗、滚动条统一圆角、阴影与过渡。
- 支持 `prefers-reduced-motion`，低配机器/晕动用户自动减少动画。

### 4. 命令面板
`Ctrl+K` 或右上角 `⌘K`：新建项目、新建章节、保存版本、打开文笔实验室、AI 味检测、专注模式、全文搜索、切换主题、API 设置、导出等，一个输入框搞定。

### 5. 更顺手的细节
- 自动保存状态显示「保存中… / 已保存 14:32:05 / 保存失败」。
- 静态资源长缓存 + 启动版本参数；主题切换过渡克制。
- 3.0 默认端口 **8082**，2.0 保持在 8081，两个版本可以同时运行、互不干扰。

## 快速开始

### Windows（推荐）

1. 双击 **`start.bat`**。
2. 浏览器打开 <http://127.0.0.1:8082/>。
3. 右上角 **🔑 API** 填 Key（也可以先写，AI 功能稍后再配）。

> 不配置 Key 也能使用编辑器、设定库、章节管理、批注、文笔分析等本地功能；只有「精修 / 生成」需要模型。
> GitHub 源码不包含 `server.exe`。首次运行需要安装 Go 1.26+，`start.bat` 会自动构建；修改源码后运行 `build.bat` 更新程序。

### 命令行

```bat
cd /d 本目录
server.exe
```

或从源码运行：

```bat
go run ./cmd/server
```

停止服务：双击 `stop.bat`。

## 核心能力（继承 2.0）

### AI 创作
- 多 Agent 流水线：规划师搭大纲 → 主笔写正文 → 校验官查人设/世界观/逻辑 → 按需回炉。
- 9 种创作模式：智能协同、自由写作、快速草稿、指派 Agent 模型、手动自选、严谨、文艺、协同闭环、轻量快捷。
- 多候选、专业模式 8 字段、逐字段 AI、AI 大纲 / 世界观 / 角色名、选中文字扩写/缩写/改写/润色/续写/氛围。
- AI 味检测、去 AI 味、字数预检、逻辑自检、RAG 预览、联网检索、人物关系图谱、伏笔扫描。

### 写作与编辑
- 富文本 + Markdown 双模式；多主题（极光金墨、经典深/浅、墨韵书斋、鎏金、沉浸专注、纸墨书香、暮色余晖）。
- 卷 / 章节管理、拖拽排序、拆分合并、回收站、版本历史、全文搜索。
- 自动保存、冲突保护、字数统计、批注 / 高亮 / 阅读进度。

### 设定与资料
- 人物卡、世界观 4-tab（设定/势力/地点/时间线）、人物关系库、伏笔看板、场景卡、素材库、文风样本、拆书导入。

### 模型与数据
- 任意 OpenAI 兼容接口 + 网页 AI（Cookie）接入。
- 角色与模型解耦，主模型 + 多级备用，失败降级。
- 本地 SQLite，启动一致性备份，导出 DOCX / TXT / Markdown。

## 配置

配置文件：`configs/config.yaml`（模板：`configs/config.yaml.example`）。

```yaml
server:
  listen_addr: 127.0.0.1
  port: 8082
  sqlite_path: data/ai-novel.db
  auth_password: ""        # 留空 = 本机免密
  library_dir: data/library
```

API Key 支持三种写法：

1. `configs/config.yaml` 的 `models[].api_key`。
2. 启动后在「API」面板填写（写入本地数据库，空 Key 不会覆盖已有 Key）。
3. 环境变量：`AI_NOVEL_MODEL_<模型名大写并用下划线替换横线>_APIKEY`。

## 3.0 还没做的

- **精修仍依赖模型**：文笔实验室能指出问题，但「精修」是否真的更好取决于所用模型；所以保留预览和替换前备份，不自动覆盖。
- **离线编辑器不完整**：富文本内核走 CDN，断网时会回退 Markdown；写作不受影响，但不是完整离线富文本。
- **移动端仍以写作为主**：已适配写作、创作助手与文笔分析；复杂的模型管理与批量设定操作建议在桌面完成。
- **没有云同步/多人协作**：3.0 仍是本地优先单机工具，冲突检测只覆盖同机多窗口。
- **没有 EPUB / 排版级导出**：目前提供 TXT / Markdown / DOCX。

## 常见问题

**打不开页面？**
确认 `server.exe` 已启动，端口 8082 没被占用；看 `log/`。

**启动后还是 2.0 界面？**
3.0 用 8082，2.0 用 8081。请确认地址是 `http://127.0.0.1:8082/`，顶部应有 **AI Novel Studio v3.0** 徽标和 ✒️ 文笔下拉。

**没有 Key 能做什么？**
编辑、章节、设定、批注、文笔分析、导出都能用；生成和精修需要 Key。

**精修会不会弄丢原文？**
替换前会自动保存一个「文笔精修前备份」版本，可在版本历史回滚。

**文笔分低怎么办？**
先看文笔实验室里的「可改进项」，从副词密度、句长波动、感官密度这三个最容易改的指标开始。

**数据在哪里？**
`data/ai-novel.db`；迁移电脑复制整个 `data/` 即可。
